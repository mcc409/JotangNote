# Question1
- HTTP 请求包含四部分
1. 请求行：方法 + 路径 + 版本，例如 GET /api/notes/1 HTTP/1.1
2. 请求头：附加信息，如 Content-Type、Authorization
3. 空行：分隔头和体
4. 请求体：POST/PUT 时携带的数据，GET 一般没有

- HTTP 响应包含四部分
1. 状态行：版本 + 状态码 + 描述，例如 HTTP/1.1 200 OK
2. 响应头（Headers）：附加信息，如 Content-Type: application/json
3. 空行：分隔头和体
4. 响应体（Body）：服务器返回的数据，如 JSON 内容
# Question2
- 用POST合适
- 原因：
1. 长篇笔记内容长，放 URL 里放不下（GET 的参数在 URL 里，长度有限）
2. 提交操作会改变服务器数据，应该用 POST，其可以改变数据
3. POST 的参数放在请求体里，更安全、容量也更大
# Question3
- 状态码：状态码是服务器告诉客户端“请求处理结果”的三位数字。
- 常见状态码：
200 成功
201 已创建
400 请求错误
401 未认证
500 服务器错误
- JotangNate中：
200 成功 查询笔记成功
201 已创建 新建笔记成功
400 请求错误 参数格式不对
403 无权限 想改/删别人的笔记
404 资源不存在 查询的笔记 ID 不存在
