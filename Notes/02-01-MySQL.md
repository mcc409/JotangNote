# Question2
1.  有索引（像字典的目录）
建好索引后，MySQL 不用全表扫描，直接跳到目标位置。

2.  数据放在内存里操作（不是每次都读硬盘）
硬盘读取慢，内存读取快几百倍。
MySQL 会把常用的数据提前加载到内存缓冲池里，查的时候直接从内存拿。

3. 存储结构专门为查询设计（B+ 树）
B+ 树是一种专门让“查找”变快的数据结构。
它把数据分层组织，每一层都能排除一大批不需要的数据，几层就能定位到目标。
