# Question1
- JSON 是一种纯文本的数据交换格式，用键值对表示数据,如：

```json
{
  "id": 123,
  "title": "我的第一篇笔记",
  "content": "今天学了 Spring Boot...",
  "author": "peng4",
  "tags": ["Java", "后端", "笔记"],
  "createdAt": "2026-10-12T16:31:00"
}
```
- JSON 用 {} 表示对象，用 [] 表示数组，键和字符串必须用双引号。
# Question2
Java 里常用 Jackson 来做这个转换。Spring Boot 默认用 Jackson。

方向一：Java 对象 → JSON（即序列化）如：

```java
ObjectMapper mapper = new ObjectMapper();

Note note = new Note(123, "我的第一篇笔记", "今天学了 Spring Boot...", "peng4");

// 转成 JSON 字符串
String json = mapper.writeValueAsString(note);
System.out.println(json);
// 输出：{"id":123,"title":"我的第一篇笔记",...}
```

方向二：JSON → Java 对象（即反序列化）如：

```java
String json = "{\"id\":123,\"title\":\"我的第一篇笔记\",\"content\":\"...\",\"author\":\"peng4\"}";

ObjectMapper mapper = new ObjectMapper();
Note note = mapper.readValue(json, Note.class);
System.out.println(note.getTitle());
// 输出：我的第一篇笔记
```
即 Java 里用 Jackson 等库把对象转成 JSON，或把 JSON 转成对象；在 Spring Boot 里，这个过程是自动完成的。
