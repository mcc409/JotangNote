# 接口问题
设计这个接口，需要考虑以下 7 个方面：
1. URL 路径

用 GET /api/notes/{id}，其中 {id} 是笔记的唯一编号。

2. 请求方法

用 GET，因为只是查询，不修改数据。

3. 请求参数

· 路径参数：id（笔记 ID）

4. 响应数据

返回 JSON，包含笔记的详细信息：

```json
{
  "id": 123,
  "title": "我的第一篇笔记",
  "content": "今天学了 Spring Boot...",
  "author": "peng4",
  "createdAt": "2026-10-12T16:31:00"
}
```

5. 状态码

· 200：查询成功
· 404：笔记不存在
· 401：未登录

6. 鉴权

需要确认用户是否有权限查看这篇笔记：

 自己的笔记：可以看
 ；别人的公开笔记：可以看
； 别人的私密笔记：返回 403

7. 错误处理

统一错误格式：

```json
{
  "code": 404,
  "message": "笔记不存在"
}
```
